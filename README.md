# Retain App

This repository contains the Retain expense-tracking application.

## Project structure

- `backend/` - Express API, Prisma schema, authentication, validation, and business logic.
- `frontend/` - React/Vite client application.

## Getting started

Install dependencies from each application directory:

```bash
cd backend
npm install

cd ../frontend
npm install
```

Copy each `.env.example` file to `.env` and provide the required local values before running the applications.
